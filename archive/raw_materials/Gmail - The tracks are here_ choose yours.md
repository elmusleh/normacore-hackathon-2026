The HackLab Robotics X BRISA - Berlin Robotics & Intelligent Systems Association Hackathon is only a few days away, and here are the tracks you'll be hacking on:

Durance AI – Durance Robot Lab: "Give a robot dog its next reflex"
Build a new event-vision behavior for a Unitree Go2 X: record data, train a spiking neural network, deploy it on a Kria KV260 board and make the robot react through ROS 2.

X Square Robot – Bring any object. Give any instruction. Challenge the robot.
Bring your own objects, design your own manipulation tasks and use the X Square API to get the robot to complete them. No scores: everyone who takes part gets a prize.

Prior Labs – TabPFN for spatial awareness
Use TabPFN's in-context learning to help robots and agents predict where things are, where they're going and what happens next. How far can a table take a robot?

Almedia – Agentic monitoring for an ads marketplace app
Build AI agents that monitor and keep a real ads marketplace app running smoothly.

Hugging Face – Desk Hero
Solve a simple everyday problem on your desk using LeRobot and any robot you want.

NormaCore – AI-Powered Robot Control
Integrate the Station API into Codex or Claude so it can control the robot by looking through the cameras.
