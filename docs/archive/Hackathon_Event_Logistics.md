## 5. Overview of All Event Tracks (Context Reference)

While your focus is **NormaCore**, the hackathon features 7 specialized tracks:

1. **NormaCore (Our Track):** *AI-Powered Robot Control* — Integrate NormaCore Station API with Claude/Codex to command a 7+1 DOF ElRobot arm with camera vision.
2. **Durance AI:** *Give a robot dog its next reflex* — Event-camera vision, Spiking Neural Networks (SNN), AMD Kria KV260 edge board, ROS 2 on a Unitree Go2 X quadruped.
3. **Hugging Face:** *Desk Hero* — Desktop task automation with SO-101 leader-follower arms and PyTorch LeRobot imitation learning policies (ACT / Diffusion / SmolVLA).
4. **Prior Labs:** *TabPFN for spatial awareness* — Instant in-context tabular foundation model inference applied to 3D trajectory forecasting and physical dynamics.
5. **X Square Robot:** *Bring any object. Give any instruction.* — General manipulation API challenge with open object sets.
6. **Almedia:** *Agentic monitoring for an ads marketplace app* — Building autonomous multi-agent systems for live operational marketplace monitoring.
7. **Dream Labs:** *Simulation Track* — Simulation-first robotics challenge.
